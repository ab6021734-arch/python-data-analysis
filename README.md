# python-data-analysis

## Описание проекта
Итоговый проект по курсу «Python для анализа данных».

Цель проекта - провести разведку и анализ данных на основе датасета с резюме соискателей, размещённых на платформе HeadHunter, выявить основные закономерности и особенности распределения данных и представить результаты в виде визуализаций.

**Ссылка на исходные данные:** (https://drive.google.com/file/d/1-61ZoikTpl5NdL7WCv3CySIvu9_ueRW0/view?usp=sharing)

## Этапы работы

1. Базовый анализ структуры данных
2. Преобразование данных
3. Разведывательный анализ
4. Очистка данных

## Результаты анализа

Все графики сохранены в формате HTML и опубликованы через GitHub Pages.

1. График распределения опыта работы (Графики/experience_distribution.html)
2. График распределения зарплат (Графики/salary_distribution.html)
3. График зависимости зарплаты от города (Графики/salary_city_distribution.html)
4. График зависимости зарплаты от уровня образования (Графики/salary_education_distribution.html)
5. График зависимости зарплаты от мобильности соискателей (Графики/salary_ready_distribution.html)
